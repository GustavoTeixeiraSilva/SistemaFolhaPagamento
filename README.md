## 📌 Sobre o Projeto

O **Sistema de Folha de Pagamento** é uma aplicação desenvolvida em Java com o objetivo de facilitar o gerenciamento de colaboradores e o processamento de informações relacionadas à folha de pagamento.

O projeto foi desenvolvido como atividade acadêmica da graduação em Sistemas de Informação, colocando em prática conceitos de lógica de programação, orientação a objetos e desenvolvimento de interfaces gráficas.

A aplicação utiliza Java Swing para proporcionar uma experiência visual simples e intuitiva, permitindo a interação do usuário com as funcionalidades do sistema.

## 🚀 Funcionalidades

- Cadastro e gerenciamento de colaboradores.
- Interface gráfica para interação com o usuário.
- Organização das informações dos colaboradores.
- Processamento de informações relacionadas à folha de pagamento.
- Estruturação do código utilizando Programação Orientada a Objetos.

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Utilização |
|---|---|
| Java | Linguagem de programação |
| Java Swing | Desenvolvimento da interface gráfica |
| POO | Organização e estruturação do código |
| ArrayList | Armazenamento de colaboradores durante a execução |

Durante o desenvolvimento, foram aplicados conceitos fundamentais da programação:

## 💻 Como Executar

**Pré-requisitos:**
- Java JDK instalado.
- IDE de desenvolvimento Java, como IntelliJ IDEA, Eclipse ou NetBeans.

**Passos:**

1. Clone o repositório:

```bash
git clone https://github.com/GustavoTeixeiraSilva/Sistema-Folha-de-Pagamento.git
```

2. Abra o projeto na sua IDE.

3. Localize a classe principal `Main.java`.

4. Execute o projeto.
